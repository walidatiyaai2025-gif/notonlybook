# MDN Nova Premium

Independent Arabic-first WordPress theme for mdn-eg.com. No dependency on the previous XTRA theme or Elementor.

The theme is bilingual (Arabic/English), switches RTL/LTR automatically, and integrates with Polylang or WPML. Slider content has separate Arabic and English fields in the Customizer.

## Admin controls

- Appearance → Customize → Site Identity: upload/change logo.
- Appearance → Customize → MDN Nova Settings: three slider texts/links and contact details.
- Appearance → Menus: assign Primary and Footer menus.

## Quality baseline

Semantic HTML5, RTL/LTR, keyboard skip link, responsive layouts, reduced-motion awareness, native responsive images, WordPress title support, organization schema, minimal JavaScript and no jQuery dependency.
